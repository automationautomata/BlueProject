# СКУД

СКУД (Система Контроля и Управления Доступом) - занимается проверкой карт доступа и хранением информации о проходах.

Состоит из 3-х частей:

+ <a href="https://github.com/automationautomata/SKUD/tree/master">Ядро скуда</a> - управляет считывателями, хранит информацию о правах доступа, пользователях и картах.
+ <a href="https://github.com/automationautomata/ACS-UI">Интерфейс</a> - предоставляет возможности администратору управлять системой (настраивать права доступа добвалять пользователей и т.д.).
+ <a href="https://github.com/automationautomata/Card-Controller">Считыватель карт</a> - проверяет право на доступ к помещению.
